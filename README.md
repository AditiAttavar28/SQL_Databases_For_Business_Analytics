# SQL Databases for Business Analytics  
### Entertainment Industry Case Study – TuneWorks

## 📌 Project Overview
This project is a comprehensive **business analytics case study** conducted for **TuneWorks**, a mid-sized entertainment agency managing entertainers, clients, agents, and bookings.  

Acting as consultants at *McBrainsey & Co.*, our goal was to **unlock the value of TuneWorks’ relational database** by applying **SQL-driven exploratory analysis**, supported by **visualizations and AI-assisted analytics**, and deliver **actionable business insights** for executive decision-making.

The project mirrors real-world analytics practice by combining:
- Independent SQL analysis  
- Python-based analytics and visualization  
- AI (ChatGPT) collaboration and comparison  

---

## 🎯 Objectives
- Explore and understand the TuneWorks relational database
- Build a **data dictionary** documenting tables, columns, and relationships
- Perform **Exploratory Data Analysis (EDA)** using SQL
- Identify business patterns across entertainers, agents, customers, and engagements
- Generate **data-backed insights and strategic recommendations**
- Compare independent analysis with **ChatGPT-assisted analysis**
- Deliver findings in **professional technical and executive-ready formats**
